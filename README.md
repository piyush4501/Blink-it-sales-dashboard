# Blinkit Sales & Outlet Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Power BI dashboard** created to analyze Blinkit's sales performance, outlet characteristics, item categories, customer ratings, and item visibility.

The dashboard provides a consolidated view of key business KPIs and helps identify sales patterns across different outlet types, outlet sizes, locations, and item categories.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Data Visualization** – Interactive charts, slicers, and tables

## 🎯 Key KPIs

The dashboard highlights the following important metrics:

- **Total Sales:** $1.20M
- **Average Sales:** $141
- **Average Rating:** 3.9
- **Number of Items:** 8,523

## 📌 Dashboard Features

### 1. Sales Performance
- Year-wise outlet establishment sales trend
- Total sales analysis
- Average sales tracking
- Item-level sales comparison

### 2. Outlet Analysis
- Outlet size comparison
- Outlet location tier analysis
- Outlet type performance
- Sales contribution by outlet type

### 3. Item Analysis
- Total sales by item type
- Fat content analysis
- Item visibility comparison
- Category-wise performance

### 4. Interactive Filters

Users can dynamically filter the dashboard using:

- Outlet Location Type
- Outlet Size
- Item Type

## 📈 Key Dashboard Visualizations

The dashboard includes:

- KPI Cards
- Area/Line Chart
- Donut Charts
- Bar Charts
- Outlet Performance Matrix
- Interactive Slicers/Filters

## 💡 Key Insights

Based on the dashboard:

- Total sales are approximately **$1.20M**.
- **Supermarket Type1** contributes the largest share of total sales among the displayed outlet types.
- **Tier 3 outlets** show the highest sales contribution among the displayed outlet location tiers.
- Sales reached their highest displayed point around **2018**, at approximately **$205K**.
- **Low-fat items** contribute a larger share of sales than regular-fat items in the dashboard.
- Fruits and vegetables and snack foods are among the leading item categories by total sales.
- The average customer rating displayed is **3.9**.

1. Download the `.pbix` file from this repository.

3. Interact with the filters and visualizations to explore the data.
4. Use the slicers to analyze sales based on outlet location, outlet size, and item type.
